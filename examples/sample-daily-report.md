### 1. bilawalsidhu/gods-eye-view

- **它在做什么：** 把公开的实时空间数据放到一个可交互的 3D 地球里，让人用类似“卫星态势图”的方式浏览。
- **有意思的点：** 可视化外壳很直观，项目重点不是再造地图，而是把多种公开数据放进同一个空间界面。
- **适合谁：** 对开源情报、地理数据可视化或 Web 3D 感兴趣的人。
- **需要注意：** “数据真实”是维护者的项目定位；数据完整性、时效和用途仍要逐数据源核实。本次元数据补全失败，因此不猜测许可证。
- **推荐理由：** 本次日增 Star 最高，而且同时出现在日榜和周榜候选中。

### 2. JustVugg/colibri

- **它在做什么：** 尝试用一个纯 C、零第三方依赖的小型引擎，在本地硬件上运行 MoE 大模型，并按需从磁盘读取专家参数。
- **有意思的点：** 它把重点放在“无需一次把整个大模型塞进内存”，思路对受限硬件很有吸引力。
- **适合谁：** 喜欢本地推理、底层性能优化和极简运行时的开发者。
- **需要注意：** 快照显示项目创建时间较短；性能、模型兼容范围和稳定性需要通过官方文档与实际测试继续确认。许可证为 Apache-2.0。
- **推荐理由：** GitHub Trending 原始位置第 1，且本次日增 960 Star。

### 3. ever-co/ever-gauzy

- **它在做什么：** 一个覆盖 ERP、CRM、招聘、人力、工时和项目管理的开源业务管理平台。
- **有意思的点：** 功能范围很完整，适合研究“一个系统覆盖多种公司内部流程”的产品路线。
- **适合谁：** 想自托管业务管理软件，或研究 TypeScript 大型业务系统的人。
- **需要注意：** 功能面广也意味着部署和维护成本可能更高；AGPL-3.0 对网络服务场景有明确开源义务，采用前应自行核对许可证。
